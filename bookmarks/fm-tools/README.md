# Master.dev 工具

> 建議書籤名稱：`Master.dev 工具 v1.0.0`

## 功能

點書籤後，在畫面右下角開一個浮動面板，整合三個 Frontend Masters 書籤的功能：

| 按鈕 | 快捷鍵 | 功能 | 原書籤 |
|---|---|---|---|
| 目前這題轉 MD（文件 icon） | `⌥⇧1` | 把目前的 Quiz／Flashcard 轉成 Markdown 並複製 | [FM 學習卡轉 Markdown](../fm-learning-md/) v1.1.0 |
| 學習卡批次複製（疊層 icon） | `⌥⇧2` | 從第一張開始逐張擷取 Flashcard，合併後一次複製 | [FM 學習卡批次複製](../fm-flashcard-batch/) v1.0.0 |
| 逐字稿複製（字幕框 icon） | `⌥⇧3` | 把 Transcripts 面板的逐字稿整理成純文字並複製 | [FM 逐字稿複製](../fm-transcript-copy/) v1.1.0 |

三個功能的轉換規則、流程和限制都和原書籤相同，詳細說明請看各原書籤的 README。唯一的差異是逐字稿複製：

- **自動關閉逐字稿面板**：如果 Transcripts 面板是書籤自己打開的，複製成功後會再點一次 Transcripts 按鈕把它關掉。
  - 執行前面板就已經開著的話，不會關閉。
  - 逾時或複製失敗時也不會關閉，這樣重試時可以直接複製，不用重新等待載入。
  - 只有在面板仍帶有 `.FMPlayer2-Transcripts.active` 時才會點。網站改掉這個 class 時，書籤寧可不關，也不會反過來把面板打開。

### 面板

- **拖曳**：拖曳標題列（或最小化後的膠囊）就能移動，移動範圍限制在視窗內。
- **最小化**：按標題列的「－」，面板會縮成一顆「Master.dev」膠囊；按膠囊上的展開鈕就會還原。
- **關閉**：按「✕」會移除面板，快捷鍵也一起停用。要再使用時，重新點一次書籤。
- **重複點書籤**：面板已經存在時不會建立第二個；如果面板是最小化的，會把它展開。
- **不記住位置**：每次點書籤都從右下角展開。頁面重新載入後面板會消失，必須重新點書籤。
- **快捷鍵**：`⌥⇧1`～`⌥⇧3`（Windows／Linux 是 `Alt+Shift+1`～`3`）。
  - 面板最小化時快捷鍵仍然有效。
  - 焦點在輸入框時不觸發；長按也不會重複觸發。
- **執行中的視覺提示**：
  - 面板（或膠囊）外框亮起，標題列下方出現來回跑的進度條。
  - 執行中的按鈕 icon 換成轉圈，右邊顯示進度，例如「第 12 張」「載入中」。
  - 執行期間其他按鈕和「✕」都會停用。這時再按快捷鍵，會顯示 `指令執行中`。

## 目的

三個書籤常常在同一個學習流程裡輪流使用。整合成一個面板後，只要安裝一個書籤，可以用滑鼠或快捷鍵觸發，也能隨時看到指令是否還在執行。

## 使用情境

1. 在 Frontend Masters 課程頁或 Learning Mode 點書籤，右下角會出現面板。
2. 點面板上的按鈕，或按對應的快捷鍵。
3. 面板擋到內容時，可以把它拖開或最小化。

## 回饋訊息

各功能的 toast 訊息和原書籤相同，請看原書籤 README 的〈回饋訊息〉。以下是面板新增或不同的部分：

| 訊息 | 類型 | 觸發時機 |
|---|---|---|
| `指令執行中` | info | 執行中又按了快捷鍵 |
| `批次複製執行中` | info | 舊版「FM 學習卡批次複製」書籤正在執行（兩者共用執行中標記，不會同時跑） |
| `執行失敗：…` | error | 指令發生未預期的錯誤；面板會解除執行中狀態 |

## 限制

- 原書籤的所有限制都適用，例如剪貼簿時限、selector 依賴、批次的逾時判斷等。
- **快捷鍵與「反應圖」書籤衝突**：[反應圖](../reaction-image/) 也使用 `Alt+Shift+1`～`9`。兩者同時啟用時，先啟用的那一個會收到按鍵，另一個不會。
- **Windows**：`Alt+Shift` 也是 Windows 預設的切換輸入法組合鍵，尚未實測是否會互相干擾。
- 頁面整頁重新載入後，面板會消失。如果是 SPA 內部換頁，面板會保留，但這部分沒有實測過。
- 面板不注入 `<style>`，以免被嚴格的 CSP 擋下。因此按鈕只有滑鼠移入時的底色變化，沒有鍵盤焦點的樣式。
- 轉圈和進度條動畫使用 Web Animations API。不支援的瀏覽器不會有動畫，但外框亮起和進度文字仍會顯示。

## 安裝

1. 複製同資料夾 `bookmarklet.txt` 的整行內容（以 `javascript:` 開頭）。
2. 瀏覽器新增書籤，名稱填 `Master.dev 工具 v1.0.0`，網址貼上剛剛複製的內容。

> Firefox 在網址欄直接貼上 `javascript:` 時會把前綴移除。請在「新增書籤」對話框的網址欄貼上。
