# 書籤名稱

> 建議書籤名稱：`書籤名稱 v1.0.0`（名稱帶版本號，才能對照本文件判斷是否需要更新）

## 功能

這個書籤做了什麼（逐項列出）。

## 目的

為什麼需要它、解決什麼問題。

## 使用情境

- 在哪個網站／頁面、什麼狀態下使用
- 操作步驟

## 回饋訊息

| 訊息 | 類型 | 觸發時機 |
|---|---|---|
| `已複製` | success | 複製成功 |
| `複製失敗` | error | clipboard API 與 fallback 都失敗 |

## 限制

- 依賴的 selector／頁面結構（網站改版可能失效）
- 不支援的網站或情境（例如頁面 CSP 禁止執行書籤）
- 其他已知問題

## 安裝

1. 複製同資料夾 `bookmarklet.txt` 的整行內容（以 `javascript:` 開頭）。
2. 瀏覽器新增書籤，名稱填 `書籤名稱 v1.0.0`，網址貼上剛剛複製的內容。
