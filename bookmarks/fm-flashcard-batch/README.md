# FM 學習卡批次複製

> 建議書籤名稱：`FM 學習卡批次複製 v1.0.0`

## 功能

在 Frontend Masters Learning Mode 的 Flashcard 畫面上，自動回到第一張，然後逐張按 Next 擷取每張卡片，最後合併成一份 Markdown 並一次複製。

- 每張卡片的格式和 [FM 學習卡轉 Markdown](../fm-learning-md/) 的 Flashcard 輸出相同（共用 `shared/lm-md.js`）：`### 正面` + 空行 + 背面。
- 卡片與卡片之間空一行。

```
### What is the purpose of not using Shadow DOM for repeated web components?

To share the document and CSS across the page, ...

### Why do you need to import a web component's JavaScript file ...?

To execute `customElements.define()`, ...
```

## 目的

一次把整組 Flashcard 整理成筆記，不用一張一張複製。

## 使用情境

1. 在 Learning Mode 開到任一張 Flashcard。
2. 點擊書籤。它會自動回到第一張，再逐張往後擷取，過程中會顯示進度。
3. 看到 `已複製 N 題` 後，就可以貼到筆記。如果出現藍色的「點此複製」按鈕，點它一下即可（原因見〈限制〉）。

## 流程

1. **回到第一張**：一直點 Previous（`.LM-Content-Actions-prev-btn`），直到按鈕不存在或 disabled。
   - 如果 Previous 退到了非 flashcard 的步驟，就點一次 Next 回到第一張卡。
2. **逐張擷取**：擷取目前這張，再點 Next（`.LM-Content-Actions-next-btn`），等到換成下一張，重複這個步驟。以下情況停止：
   - Next 不存在或 disabled，或是 Next 進到了非 flashcard 的步驟 → 正常結束。
   - 已處理 100 張 → 達上限。
   - 點了 Next 之後 3 秒內卡片都沒換 → 逾時。
3. **複製**：合併後一次複製。

### 如何判斷「已換成下一張」

- **條件**：點擊後，正面和背面（節點或文字）都和點擊前不同，而且連續兩次檢查（間隔 100ms）結果相同。
- **目的**：避免擷取到「新正面 + 舊背面」。
- **逾時時**：只要有任一面改變，仍然視為已換卡（例如相鄰兩張的背面剛好相同，網站又沿用同一個節點）。

## 回饋訊息

| 訊息 | 類型 | 觸發時機 |
|---|---|---|
| `回到第一張…` | info（不自動消失） | 正在往前翻 |
| `複製中… 第 N 張` | info（不自動消失） | 正在擷取 |
| `已複製 N 題` | success | 完成 |
| `…，略過 M 張` | success（附加） | 有卡片缺正面或背面 |
| `…（逾時中止）` | success（附加） | 點 Next 後 3 秒內沒換卡 |
| `…（達上限中止）` | success（附加） | 處理滿 100 張 |
| `已擷取 N 題，點此複製` | 可點擊按鈕 | 自動複製失敗時（見〈限制〉） |
| `找不到 flashcard 內容` | error | 頁面上沒有 Flashcard，或整組都沒有擷取到內容 |
| `無法回到第一張` | error | 點 Previous 後 3 秒內沒換卡 |
| `批次複製執行中` | info | 執行期間又點了一次書籤（不會重跑） |
| `複製失敗` | error | 點按鈕後仍然複製失敗（按鈕會保留，可以再試） |

## 限制

- **剪貼簿時限**：瀏覽器只允許在使用者點擊後的短時間內寫入剪貼簿，Firefox 約 5 秒，Safari 更嚴格。批次跑得比較久時，自動複製會失敗，改成顯示「點此複製」按鈕，點一下就能複製。Chrome 只要分頁在前景，通常會直接成功。
- **最後一張的判斷**：我沒看過最後一張的 Next 實際長什麼樣子。如果它仍然可以點、只是點了沒反應，書籤會等 3 秒逾時才停，toast 會標示「逾時中止」，但複製出來的內容仍然完整。
- **非 flashcard 步驟的處理未經實測**：Previous／Next 可能會進到前後的學習步驟（例如 Quiz），這部分的處理是依推測實作的。如果實際行為不符合預期，請提供對應的 HTML。
- **相鄰兩張完全相同的卡**：正反面的內容和節點都完全相同時，書籤無法判斷已經換頁，會提早以「逾時中止」結束。
- **不要在執行中切到其他分頁**：瀏覽器可能會延遲背景分頁的計時器，逾時是用實際經過的時間計算的，所以可能提早判定逾時。
- 執行中標記存放在 `<html data-__bmt_fm_batch="時間戳">`，結束時移除。即使中途出錯沒有移除，約 4 秒後也會自動失效。

## 安裝

1. 複製同資料夾 `bookmarklet.txt` 的整行內容（以 `javascript:` 開頭）。
2. 瀏覽器新增書籤，名稱填 `FM 學習卡批次複製 v1.0.0`，網址貼上剛剛複製的內容。
