# LCS 工具

> 建議書籤名稱：`LCS 工具 v1.0.0`

## 功能

在 [LearnCraft Spanish](https://www.learncraftspanish.com/) 的 podcast 頁點擊書籤後，畫面右下角會出現浮動面板，並**自動執行**以下三件事，最後顯示一則彙總 toast：

1. **專注模式**：移除頂部導覽列，播放器貼齊畫面頂端。邏輯和 [LCS Podcast 專注模式](../lcs-podcast-focus/) v1.1.0 相同。
2. **模糊西文**：把所有 `strong em`（網站用來標示西班牙文的元素）模糊。
3. **播放器加上 ±5 秒按鈕**：控制列變成〔1x〕〔⏪ 5s〕〔⏪ 15s〕〔30s ⏩〕〔5s ⏩〕。

### 面板指令

| 按鈕 | 快捷鍵 | 功能 |
|---|---|---|
| 專注模式 | `⌥⇧1` | 再執行一次專注模式（例如網站重新產生了導覽列） |
| 重新模糊 | `⌥⇧2` | 把所有 `strong em` 重新模糊，包括已經點開的字和之後才出現的字 |
| 倒轉 5 秒 | `⌥⇧3` | 播放位置 −5 秒，最小到 0 |
| 快進 5 秒 | `⌥⇧4` | 播放位置 +5 秒，最大到音檔長度 |

面板的拖曳、展開／縮小／最小化、快捷鍵規則和執行中提示，都和 [Master.dev 工具](../fm-tools/) 相同，詳見 `shared/README.md` 的 panel 章節。

### 模糊

- 點一下模糊的字會顯示，再點一下會重新模糊，可以反覆自我測驗。
- 字在連結裡面時，點擊只會切換模糊，不會跳轉頁面。按住 ⌘／Ctrl／Shift／Alt 點擊時不切換，照常開連結（例如在新分頁開啟）。
- 拖曳選取文字、放開在模糊字上時不切換。
- 只改 `filter` 和 `cursor`。會記住元素原本的 inline `filter`（含 `!important`），顯示時還原，不會清掉網站自己的樣式。`cursor` 顯示後仍維持 pointer，表示可以再點一下模糊。
- 書籤執行後才出現的 `strong em` 不會自動模糊。要模糊這些字，請按「重新模糊」。

### ±5 秒按鈕

- 由播放器原本的 15s／30s 按鈕複製而來，沿用原本的 class 和圖示，外觀和原生按鈕一致。複製時會去掉 `id`、`title`、inline `on*` 屬性和停用狀態（`disabled`、`aria-disabled`、含 disabled 的 class），文字中的「15s」「30s」改成「5s」。
- 點擊在 `window` capture 階段處理並攔截，播放器自己的點擊委派收不到，不會把它當成原生 15s／30s 鈕。這兩顆按鈕交給網站 CSS 決定外觀，所以不套用 design tokens，是設計系統規範的例外。
- 直接修改 `<audio>` 的 `currentTime`，不經過播放器內部。成功時按鈕不顯示 toast，比照原生按鈕；找不到音訊時顯示 error。面板指令則會顯示新的位置。
- 播放器重新繪製（例如切換速度）造成按鈕消失時，會自動補回（約 0.1 秒內）。播放器比書籤晚出現時，出現後也會自動補上。
- 如果 2 秒內需要補回超過 5 次（網站一直移除按鈕），就停止補回並顯示 error，避免和網站互相拉扯。
- **關閉面板（✕）時，兩顆按鈕會一起移除，並停止監看。** 模糊字仍然可以點擊切換。

### 重複點書籤

- 面板已經存在時，只會還原面板（例如從最小化還原），不會重新模糊，也不會重複插入按鈕。要重新模糊，請用 `⌥⇧2`。
- 換成新版書籤後再點，舊版面板如果閒置，會被換成新版。

## 目的

用 podcast 逐字稿練習西班牙文：先看英文句子，自己在心裡翻譯，再點模糊的西文對答案。同時用 ±5 秒反覆聽同一句。

## 使用情境

1. 打開任一 podcast 頁面，例如 `https://www.learncraftspanish.com/podcast/necesitar-and-mirar`。
2. 點擊書籤。導覽列消失，西文被模糊，播放器多出 ±5s 按鈕。
3. 點模糊的字看答案；用播放器上的按鈕或 `⌥⇧3`／`⌥⇧4` 倒轉、快進。
4. 一輪結束後按 `⌥⇧2`，全部重新模糊。

## 回饋訊息

開啟時的彙總訊息由三段組成，以「・」連接：

| 段落 | 成功時 | 找不到時 |
|---|---|---|
| 專注模式 | `移除 sticky-nav ×N・播放器 top → 0px`（或其中一項） | `找不到導覽列與播放器` |
| 模糊 | `模糊 N 處` | `找不到 strong em` |
| ±5s 按鈕 | `已加入 ±5s 按鈕` | `找不到播放器按鈕` |

只要有一段成功，類型就是 success；三段都失敗時是 error。

| 訊息 | 類型 | 觸發時機 |
|---|---|---|
| 和原書籤相同（例如 `移除 sticky-nav ×1・播放器 top → 0px`） | success | `⌥⇧1` 找到目標 |
| `找不到目標元素` | error | `⌥⇧1` 導覽列和播放器都找不到 |
| `已模糊 N 處` | success | `⌥⇧2` |
| `找不到 strong em` | error | `⌥⇧2` 頁面上沒有 `strong em` |
| `−5s → 01:23`／`+5s → 01:33` | success | `⌥⇧3`／`⌥⇧4`，顯示新的播放位置 |
| `找不到音訊` | error | `⌥⇧3`／`⌥⇧4` 或播放器上的 ±5s 鈕：頁面上沒有 `<audio>` |
| `播放器按鈕一直被移除，已停止補回` | error | 2 秒內補回超過 5 次 |
| `舊版面板執行中，請稍後再點一次` | error | 換成新版書籤後點擊時，舊版面板仍在執行 |

面板共用的訊息（`指令執行中`、`執行失敗：…` 等）請見 [Master.dev 工具](../fm-tools/) 的〈回饋訊息〉。

## 限制

- 依賴 LearnCraft Spanish 的頁面結構：`.v2-section.sticky-nav`、`#podcast_player_container`、`strong em`、Fusebox 播放器的 `.fbx-time-shift-button.fbx-backward`／`.fbx-forward`。網站改版後可能失效。
- 只控制頁面上第一個 `<audio>`。
- 監看播放器重繪使用 MutationObserver，會持續到關閉面板或重新整理頁面為止。
- 專注模式是單向的，要還原請重新整理頁面。
- **快捷鍵與「反應圖」、「Master.dev 工具」衝突**：它們也使用 `Alt+Shift+數字`。同時啟用時，先啟用的那一個會收到按鍵。
- 點擊委派只綁定一次，但切換函式記在 `<html>` 上，每次執行書籤都會換成目前版本，所以換新版後不必重新整理。
- 如果網站重繪時重設了字的樣式，字會變回清楚，但書籤仍記得它是「模糊中」，要點兩下才會再模糊；按 `⌥⇧2` 也可以全部重新模糊。
- 模糊的字只能用滑鼠點擊切換，無法用鍵盤操作；也沒有「全部顯示」的指令。

## 安裝

1. 複製同資料夾 `bookmarklet.txt` 的整行內容（以 `javascript:` 開頭）。
2. 瀏覽器新增書籤，名稱填 `LCS 工具 v1.0.0`，網址貼上剛剛複製的內容。

> Firefox 在網址欄直接貼上 `javascript:` 時會把前綴移除。請在「新增書籤」對話框的網址欄貼上。
