# 反應圖

> 建議書籤名稱：`反應圖 v1.1.0`

## 功能

- 在頁面**右下角**顯示你自己的圖片（例如 GIF、貼圖）。圖片最長邊 240px，距離邊緣 20px。
- 可以**拖曳**到任意位置，也可以用**滾輪縮放**。位置和大小只在這次開啟的頁面裡有效，重新整理後回到右下角、240px。
- 最多可以設定 **9 張**，用快捷鍵 **Alt+Shift+1～9** 切換（Mac 上是 Option+Shift+數字）。
- 圖片網址會記在這個網站的 `localStorage`，下次直接顯示。

## 目的

在分享螢幕或開會時，快速秀出一張表情或反應圖。

## 使用情境

1. 開會前，在要分享的分頁上點一次書籤。
   - 第一次使用時，會請你貼上第 1 張圖片的網址。
   - 之後每次點書籤，都會直接顯示最後使用的那一張。
   - 點書籤的同時，這個分頁會開始監聽快捷鍵，畫面上方會出現 `快捷鍵已啟用：Alt+Shift+1~9`。
2. 開會中：

| 操作 | 結果 |
|---|---|
| Alt+Shift+N | 顯示第 N 張；這一格還沒設定時，會請你貼上網址 |
| 同一張正在顯示時再按 Alt+Shift+N | 關閉 |
| 點圖片 | 關閉 |
| 按住圖片拖曳 | 移動到任意位置，放開後停在那裡（移動不到 4px 仍算點擊，會關閉） |
| 滑鼠在圖片上滾動滾輪 | 以游標為中心放大／縮小（滑鼠滾輪一格約 10%，觸控板依滑動量），範圍 60px～畫面高度 |
| 滑鼠移到圖片上 → 點左上角的「更換」 | 換掉這一格的網址 |
| 滑鼠移到圖片上 → 點底部的數字 1～9 | 切換到那一格；沒有圖的數字會請你貼上網址 |

- 底部數字列：有圖的數字是白色、沒有圖的數字是暗色，目前這一張加框。滑鼠沒移到圖片上時不會顯示，所以不會出現在分享的畫面裡。
- 切換到其他張圖時，沿用目前的位置和大小。
- 拖曳或縮放後，圖片至少會留 40px 在畫面內，不會整張拖出去找不回來。
- 快捷鍵在點過書籤之後持續有效，圖片關掉也能用，直到重新整理頁面為止。
- 游標在輸入框裡時，快捷鍵也有效。
- 長按快捷鍵不會連續觸發。

## 回饋訊息

| 訊息 | 類型 | 觸發時機 |
|---|---|---|
| `快捷鍵已啟用：Alt+Shift+1~9` | info | 這個分頁第一次點書籤 |
| `圖片載入失敗` | error | 圖片載不出來；接著會再詢問一次網址 |
| `此網站可能禁止載入外部圖片` | error | 連續兩次載入失敗；之後不再詢問 |

## 儲存格式

`localStorage['__bmt_reaction']` = `{"urls":{"1":"https://…","2":"https://…"},"last":2}`

- 圖片成功載入後才會記住網址；載入失敗的網址不會被存下來。
- 內容損壞時會當作沒有設定，下次存檔時會覆寫成正確的格式。

## 限制

- **觸控裝置不支援拖曳和縮放**，而且點一下就會關閉，所以用不到「更換」和數字列。
- **圖片縮得很小時**（約 180px 以下），底部數字列會比圖片寬，可能超出圖片範圍，也可能和「更換」按鈕靠得很近。
- **新舊版並存**：這個頁面如果已經用 v1.0.0 啟用過快捷鍵，按快捷鍵時仍然是舊版的行為（不能拖曳和縮放）。重新整理頁面後再點新版書籤即可。

- **網址是依網站分開記住的**：`localStorage` 以網站為單位，所以在 A 網站設定過，到 B 網站還要再設定一次。
- **快捷鍵只在點過書籤的分頁有效**：書籤無法註冊全域快捷鍵，重新整理頁面後要再點一次書籤。
- **焦點在 iframe 裡時快捷鍵無效**：例如 Google Docs 的編輯區、嵌入式編輯器。這時先點一下頁面的其他地方再按。
- **Windows**：Alt+Shift 是系統預設的「切換輸入語言」快捷鍵，按 Alt+Shift+數字時可能會順便切換輸入法。請實機確認，如果有影響，可以到系統設定裡關閉這個快捷鍵。
- **只有別人看得到你分享的畫面時才有效**：圖片只出現在這個分頁裡，開會時要分享這個瀏覽器分頁或整個視窗，別人才看得到。
- **有些網站會禁止外部圖片**：網站的 CSP 禁止載入外部圖片時，這個書籤無法使用。
- **網站禁止 `localStorage` 時**：仍然可以顯示圖片，只是不會記住網址。

## 安裝

1. 複製同資料夾 `bookmarklet.txt` 的整行內容（以 `javascript:` 開頭）。
2. 瀏覽器新增書籤，名稱填 `反應圖 v1.1.0`，網址貼上剛剛複製的內容。
