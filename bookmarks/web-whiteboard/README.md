# 網頁白板

> 建議書籤名稱：`網頁白板 v1.0.0`（名稱帶版本號，才能對照本文件判斷是否需要更新）

## 功能

- 在目前網頁上疊一層透明白板，原本的網頁內容不會被修改。
- **兩種模式**
  - **互動模式**（預設）：白板不攔截滑鼠，可以正常操作網頁。
  - **畫圖模式**：在畫面上作畫。點工具列的「筆／橡皮擦／便利貼」會自動切到畫圖模式；按 `Esc` 或點模式鈕切回互動模式。
- **筆**
  - 6 種顏色：黑、白、紅、藍、綠、黃。白色適合深色網站。
  - 3 種粗細：2、4、8px。
  - 只點一下會畫出圓點。
- **橡皮擦**：點到或滑過的筆畫會整條刪除，不會刪到便利貼。
- **便利貼**
  - 在畫布上點一下新增，底色是目前選的顏色；選黑色時改用白底。
  - 拖曳上方的色條可以移動。
  - 拖曳右下角可以調整大小，最小 80×60。
  - 點右上角 × 刪除。
  - 不受模式影響，任何時候都能操作。
- **筆畫與便利貼會跟著頁面捲動**：記錄的是在頁面上的位置，沒有頁面長度限制。
- **清除全部**：只清除筆畫，便利貼保留。
- **復原／重做**
  - 範圍：新增筆畫、橡皮擦刪除、新增便利貼、× 刪除便利貼、清除全部。
  - 便利貼的移動、縮放、文字編輯不在復原範圍內。
  - 快捷鍵：`Ctrl/⌘+Z` 復原，`Ctrl+Y` 或 `Ctrl/⌘+Shift+Z` 重做。只在畫圖模式下有效，游標在輸入框裡時交給輸入框自己處理。
- **工具列**
  - 按住最左邊的 ⋮⋮ 把手拖曳，放開後會吸附到滑鼠最靠近的那一邊（上、下、左、右）。貼在左右兩邊時改成直向排列，太長時可以捲動。
  - 可以最小化成一顆圓鈕，點圓鈕展開。
  - 滑鼠停在按鈕上會顯示工具名稱。
- **關閉**：白板上還有內容時，會先跳出確認視窗。內容不會保存，關閉或重新整理頁面後就會消失。

## 目的

看網頁、簡報或文件時，可以直接在上面圈重點、打草稿、貼便條。不用截圖，也不會改到原本的網頁。

## 使用情境

1. 在任何網頁點書籤，工具列會出現在畫面下方。
2. 點「筆」開始畫。要操作網頁時按 `Esc` 切回互動模式。
3. 用完點工具列最右邊的 × 關閉。

## 回饋訊息

| 訊息 | 類型 | 觸發時機 |
|---|---|---|
| `白板已開啟` | success | 開啟白板 |
| `白板已開啟` | info | 白板已經開著時又點了書籤（不會重複建立） |
| `舊版白板仍開著，請先關閉` | error | 頁面上還有舊版（移轉前）的白板 |
| `已切換至畫圖模式`／`已切換至互動模式` | success | 切換模式 |
| `已清除所有筆畫` | success | 清除全部 |
| `目前沒有筆畫` | error | 沒有筆畫時按了清除全部 |
| `已復原`／`已重做` | success | 復原、重做 |
| `沒有可復原的動作`／`沒有可重做的動作` | error | 復原或重做的紀錄是空的 |
| `已關閉白板` | success | 關閉白板（在確認視窗按取消時不會顯示） |

## 限制

- **只支援滑鼠**，觸控螢幕和觸控筆無法畫圖。
- **內層捲動的網站**（例如 Gmail、Notion 等由頁面內某個區塊捲動的 SPA）：筆畫和便利貼只會跟著整個頁面捲動，不會跟著內層區塊移動；在畫圖模式下也捲不動內層區塊。
- **確認視窗被瀏覽器封鎖時**（例如勾選過「禁止此網頁再產生對話方塊」，或頁面在沙箱 iframe 內），白板上有內容時無法關閉，只能重新整理頁面。
- 網頁本身會動態重排版時（例如展開或收合區塊），筆畫不會跟著內容移動。
- 少數網站的元素層級極高，或 `<body>` 本身有特殊的疊層設定，可能讓 toast 或工具列被網站元素蓋住。
- 頁面的 CSP 禁止執行書籤時無法使用。

## 安裝

1. 複製同資料夾 `bookmarklet.txt` 的整行內容（以 `javascript:` 開頭）。
2. 瀏覽器新增書籤，名稱填 `網頁白板 v1.0.0`，網址貼上剛剛複製的內容。
